# Что нужно сделать вам

1. **Установить расширение в браузер.**
   Где: `chrome://extensions` → включить «Режим разработчика» → «Загрузить распакованное
   расширение» → выбрать папку проекта `dark-theme-for-everythhing`.
   Зачем: расширение не опубликовано в магазине, браузер ставит его только так.

   Можно поставить и готовый пакет `dist/dark-theme-everywhere.crx`: перетащите его на страницу
   `chrome://extensions` или `edge://extensions` с включённым режимом разработчика. Если Chrome или
   Edge на Windows откажется ставить `.crx` не из магазина, загрузите вместо него папку
   `dist/dark-theme-everywhere` как распакованное расширение.

2. **Сохранить в надёжном месте закрытый ключ** `keys/dark-theme-everywhere.pem` и никому его не передавать.
   Зачем: только этим ключом можно подписать обновления `.crx` с тем же ID расширения. Если ключ
   потерять, новая версия станет отдельным расширением, а настройки и список сайтов пропадут.

3. **Проверить на своих привычных сайтах** и через всплывающее окно выключить тему там,
   где она мешает (кнопка «Выключить» для сайта).
   Зачем: автоматический анализ картинок — эвристика; на отдельных сайтах может понадобиться
   ручное правило.

4. *(Только если пользуетесь Firefox)* После загрузки через `about:debugging` открыть
   `about:addons` → «Тёмная тема везде» → «Разрешения» и включить доступ ко всем сайтам.
   Зачем: в Firefox доступ к сайтам для MV3-расширений по умолчанию выключен, без него тема не применится.

5. *(По желанию, для локальных файлов)* В `chrome://extensions` → «Подробнее» у расширения
   включить «Разрешить доступ к URL файлов».
   Зачем: иначе тема не работает на открытых в браузере файлах `file://`.

6. *(Если захотите публиковать)* Зарегистрировать аккаунт разработчика в
   [Chrome Web Store](https://chrome.google.com/webstore/devconsole) (разовый взнос $5) и/или на
   [addons.mozilla.org](https://addons.mozilla.org/developers/), а в `manifest.json` заменить
   `dark-theme-everywhere@example.local` на свой ID расширения для Firefox.
   Зачем: публикация в магазинах возможна только от вашего имени.
