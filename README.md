# Тёмная тема везде

Расширение для браузера (Manifest V3), которое делает тёмным любой сайт.
Работает в Chrome, Edge, Яндекс Браузере, Opera, Brave и Firefox 121+.

## Возможности

- **Тёмная тема для любого сайта** — включая сайты с inline-стилями, canvas и iframe.
- **Переключение для всех сайтов и для конкретного сайта.** Во всплывающем окне:
  общий переключатель «Все сайты» и для текущего сайта — «Как везде / Включить / Выключить».
  Правило сайта важнее общего переключателя; правило для `example.com` действует и на поддомены.
  Полный список правил — на странице настроек.
- **Умная обработка картинок:**
  - фотографии, видео, canvas остаются в исходных цветах;
  - чёрный логотип на прозрачном фоне (который пропал бы на тёмном фоне) становится светлым;
  - белый логотип из тёмной шапки (шапка после инверсии светлеет) становится тёмным;
  - решение принимается по контрасту картинки с реальным фоном за ней, работает для `<img>`,
    SVG-файлов и иконок, заданных через CSS `background-image`;
  - светлые картинки с чёрным текстом (схемы, скриншоты документов) по желанию инвертируются.
- **Сайты, которые уже тёмные**, распознаются и не трогаются (иначе они стали бы светлыми).
  Принудительно включить тему на таком сайте можно кнопкой «Включить».
- Настройки яркости, контраста, сепии, оттенков серого и яркости картинок.
- Горячие клавиши: `Alt+Shift+D` — текущий сайт, `Alt+Shift+G` — все сайты.

## Установка (режим разработчика)

Скачайте проект:

```bash
git clone https://github.com/iisavva/dark-theme-everywhere.git
```

(или Code → Download ZIP на странице репозитория и распакуйте).

**Chrome / Edge / Яндекс / Opera / Brave**

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку (где лежит `manifest.json`).
4. Закрепите иконку расширения на панели.

**Firefox**

1. Откройте `about:debugging#/runtime/this-firefox`.
2. «Загрузить временное дополнение…» → выберите `manifest.json`.
3. В `about:addons` → расширение → «Разрешения» включите доступ ко всем сайтам
   (в Firefox для MV3 он по умолчанию выключен).

## Сборка .crx и .zip

```bash
powershell -ExecutionPolicy Bypass -File tools/build.ps1
```

Скрипт берёт установленный Chrome или Edge и создаёт:

- `dist/dark-theme-everywhere.crx` — подписанный пакет CRX3;
- `dist/dark-theme-everywhere.zip` — архив для загрузки в Chrome Web Store или на addons.mozilla.org;
- `dist/dark-theme-everywhere/` — чистая папка расширения (её можно загрузить как распакованное).

При первой сборке создаётся закрытый ключ `keys/dark-theme-everywhere.pem`. Последующие сборки
подписываются им же, поэтому ID расширения не меняется. Ключ секретный: не публикуйте его
(`keys/` и `dist/` добавлены в `.gitignore`).

Chrome и Edge в Windows обычно не дают поставить `.crx` не из магазина: появляется ошибка или
расширение сразу отключается. Для себя проще загрузить папку `dist/dark-theme-everywhere`
через «Загрузить распакованное расширение». `.crx` подойдёт для Linux/macOS, для браузеров с
мягкими правилами (Яндекс, Opera) и для установки через корпоративные политики.

## Как это устроено

| Файл | Что делает |
|---|---|
| `src/content.js` | Применяет тему: фильтр `invert + hue-rotate` на `<html>`, обратная инверсия медиа, анализ картинок, распознавание тёмных сайтов |
| `src/background.js` | Анализ картинок с других доменов (наружу отдаётся только статистика, не сама картинка), иконка на панели, горячие клавиши, связь с iframe |
| `src/shared.js` | Настройки по умолчанию, правила сайтов, статистика пикселей |
| `popup/` | Всплывающее окно |
| `options/` | Страница настроек и список сайтов |
| `tools/make_assets.py` | Генерирует иконки и тестовые картинки (`python tools/make_assets.py`, нужен Pillow) |
| `test/` | Тестовые страницы |

Картинка анализируется так: уменьшенная копия (до 96 px) рисуется на canvas, считаются доля
прозрачных пикселей, средняя яркость, доля насыщенных цветов и «бумажность» (белый фон с тёмными
штрихами). Для прозрачных картинок сравнивается контраст двух вариантов — исходного и
инвертированного — с фоном, который окажется за картинкой после затемнения, и выбирается лучший.

## Проверка без установки

```bash
python -m http.server 8766
```

Откройте `http://127.0.0.1:8766/test/index.html?stub` — там на заглушке API браузера работает
тот же `content.js`. С установленным расширением открывайте страницу без `?stub`.
`test/dark.html` — пример уже тёмного сайта.

## Ограничения

- Цветные эмодзи в тексте инвертируются вместе с текстом.
- Картинки внутри закрытого (closed) Shadow DOM не обрабатываются.
- На служебных страницах (`chrome://`, магазин расширений) браузер не разрешает расширениям работать.
- Для локальных файлов (`file://`) в Chrome нужно включить «Разрешить доступ к URL файлов»
  в карточке расширения.
